# 第1回 過去を知る意義と年代測定

年輪年代学（dendrochronology） 配布資料

90分。スライドL01_S01〜L01_S27に対応。

## 学習の目標

- 試料と知りたい出来事に合う方法を選び、何の年代が測れるか説明する。

- 年代の不確かさ（uncertainty）と時間分解能（temporal resolution）を区別する。

- 古環境の代理指標（proxy）を、年代と環境情報の両面から読む。

## 方法と対象

| 方法 | 試料・時計 | 解釈の確認点 |
| --- | --- | --- |
| 年輪年代法（dendrochronology） | 年輪の変動を照合 | 形成年と伐採・使用年の関係 |
| 放射性炭素法（radiocarbon dating） | 生物由来の炭素中の14C | 較正、汚染、炭素の由来 |
| K–Ar／Ar–Ar、U–Th | 鉱物や炭酸塩の同位体 | 時計の開始と保持、初期成分 |
| ルミネッセンス法（luminescence dating） | 光・熱でリセットされる信号 | リセットの程度と埋没環境 |
| 考古地磁気法（archaeomagnetic dating） | 焼成・冷却時の磁気 | 地域の基準曲線と移動の有無 |

## 年代の表記

1000 ± 30 BPは14C年代の表記例で、基準年は1950年。較正してcal BPやcal BCE／CEで表す。BP値をそのまま1950年から引くと、暦年になるとは限らない。年輪には検証した暦年を与える。

数値や模式図は説明用で、実在資料の測定結果ではない。

# 第1回の主要用語

日本語と英語を対応づけて読む。分野を広げた用語は共通の日英用語集を参照する。

| 日本語 | English | 短い解説 |
| --- | --- | --- |
| 年代測定 | dating | 試料や出来事を時間の中に位置づける。 |
| 編年 | chronology | 資料や出来事の時間的な並びとその枠組み。 |
| 相対年代 | relative age | ほかの対象に対する古い・新しいという関係。 |
| 数値年代 | numerical age | 年などの数値で表す年代。 |
| 暦年代 | calendar age | 暦の時間軸に位置づけた年代。 |
| 時間分解能 | temporal resolution | 記録がどの程度細かい時間間隔を区別するか。 |
| 不確かさ | uncertainty | 測定値や推定を一つの値に確定できない程度。 |
| 放射性炭素年代測定 | radiocarbon dating | 試料の14Cを利用する年代測定。 |
| 較正 | calibration | 14C年代を、較正曲線で暦年代へ対応づけること。 |
| 半減期 | half-life | 放射性核種の数が半分になる時間。 |
| 層序学 | stratigraphy | 地層の重なりや関係から形成順序などを調べる。 |
| ルミネッセンス年代測定 | luminescence dating | 鉱物が光や熱でリセットされてからの時間を測る。 |
| 古地磁気 | palaeomagnetism | 岩石などに残る過去の地球磁場の記録。 |
| 年輪年代学 | dendrochronology | 暦年に位置づけた年輪を用いて時間的変化を調べる。 |
| 代理指標 | proxy | 直接観測の代わりに環境条件を推定する手がかり。 |
| 古気候学 | paleoclimatology | 過去の気候を研究する分野。 |
| 年縞 | varve | 一年の堆積に対応すると確認された堆積物の層。 |
