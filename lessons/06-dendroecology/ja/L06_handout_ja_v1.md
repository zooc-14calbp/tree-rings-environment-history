# 第6回　年輪生態学：配布資料
樹木年輪で読む環境と歴史｜90分｜初稿 v1｜2026年10月30日

## 今日の問い
葉を食べられた履歴は、木の中に残るだろうか。森林で何が起きたかを、年輪幅、組織、傷、個体群の年齢構成から考える。到達目標は、年輪生態学（dendroecology）の問いを説明し、観察された変化とその原因の仮説を区別することである。

## 三つの記録を組み合わせる
1. 成長量：抑制・解放の時期、変化の大きさと持続、個体間の同時性を調べる。
2. 傷：火傷や損傷を年輪に位置づける。傷の原因と保存状態も確認する。
3. 個体群：更新・定着・枯死の時期を調べ、現在の森林に残っていない個体も検討する。

## 原因を考えるとき
林冠ギャップ（canopy gap）ができると、光や競争条件が変わる。一方、成長増加には気候、水分、虫害からの回復、間伐など、複数の説明があり得る。単年の広い年輪や一つの変化率だけでは原因を確定できない。反応の遅れにも注意する。

対象木と比較林分、寄主樹種と非寄主樹種を比べる方法がある。ただし、樹種・立地・サイズ・管理履歴の違いは残る。比較木が完全な対照実験になるわけではない。枯死木、切り株、稚樹、森林簿、写真、被害記録も検討する。

## 樹齢と、年輪幅の意味
採取高で1980年から年輪が残る木が、1980年に発芽したとは限らない。髄の欠失と、その高さに達するまでの時間を確認する。太い木ほど古いとは限らず、生存木だけの樹齢分布には偏りがある。

円形断面を仮定すると、断面積増分（basal area increment; BAI）＝π［（r＋w）²−r²］。rは前年の半径、wは当年の年輪幅。同じw＝1 mmでもr＝10 mmなら約66 mm²、r＝30 mmなら約192 mm²となる。半径・幹形・採取高には不確実性があり、BAIだけでバイオマスや炭素量は求められない。

## 計算と問い
1. M1を1995〜1999年、M2を2000〜2004年の平均年輪幅として求める。配布CSVでも計算できる。
2. 変化率 G＝（M2−M1）÷M1×100% と、絶対的な増分 M2−M1（mm）を求める。
3. AとDの変化率・増分を比べる。林冠ギャップを原因と断定できるか。
4. 原因の仮説を比べるための追加資料を一つ提案する。

# 演習B　火傷木の数と分母
8分：個人4分、二人で比較3分、結論の記録1分。すべて架空例。

1＝火傷の記録あり。0＝記録可能だが火傷なし。—＝記録不能。記録可能期間は教材の条件として与える。実際には、木が生きているだけで火傷を記録できるとは限らない。

| Tree | 1900 | 1920 | 1940 | 1960 |
| --- | --- | --- | --- | --- |
| T1 | 1 | 0 | 1 | 1 |
| T2 | — | 1 | 1 | 0 |
| T3 | — | — | 1 | 1 |
| T4 | — | — | — | 1 |

## 計算と問い
1. 各年の記録可能木の数と、火傷がある木の数を求める。
2. 割合＝火傷木数÷記録可能木数×100% を計算する。
3. 1940年と1960年を比べる。同じ火傷木数でも、割合は同じか。
4. 火災の規模・被害強度・周期を、この表だけで決められるか。

<!-- writing-space -->
## 解釈上の注意
記録不能を0に置き換えない。記録可能でも、火災が必ず火傷を残すわけではない。表は記録された一部の年代を選んだ架空例であり、並んだ年代の間隔が森林の全火災の周期になるわけではない。標本での火傷木割合は、焼失面積率や被害強度ではない。

## 実際の資料へ
NOAAのInternational Multiproxy Paleofire Database（IMPD、R37）では、火傷や炭化物など異なる火災履歴資料を参照できる。データを利用するときは、記録可能期間や符号の定義を確認する。ジャイアントセコイアの実例はR38、複数の証拠を組み合わせた森林発達研究はR40を参照する。

# 日英用語と短い解説
| 日本語（English） | 解説 |
| --- | --- |
| 年輪生態学（dendroecology） | 年輪から生態的な過程と森林の履歴を研究する。 |
| 林分動態（stand dynamics） | 林分内の成長・更新・枯死などの変化。 |
| 林冠ギャップ（canopy gap） | 林冠に生じた開口部。 |
| 攪乱（disturbance） | 生態系の構造や資源条件などを変える出来事。 |
| 成長抑制（growth suppression） | 比較的小さな成長が続く状態。 |
| 成長の解放（growth release） | 持続する成長増加。判定基準の明示が必要。 |
| 断面積増分（basal area increment (BAI)） | 幹の断面積の年増加量。バイオマスそのものではない。 |
| 更新（regeneration） | 稚樹の出現と育成を含む森林の世代交代。 |
| 定着（establishment） | 個体が生育場所に成立すること。採取高の初年輪とは区別。 |
| 生存者の偏り（survivorship bias） | 残った個体だけを見て生じる推論の偏り。 |
| 火傷（fire scar） | 火災による形成層の損傷などが残した記録。 |
| 記録可能木（recording tree） | その時点で火傷を記録・保存し得ると判断した木。 |
| 食葉（defoliation） | 昆虫などによる葉の喪失。 |
| 年輪昆虫学（dendroentomology） | 年輪を用いて虫害など昆虫の履歴を研究する分野。 |
| 年輪内密度変動（intra-annual density fluctuations (IADFs)） | 一つの年輪内での密度・組織の変化。虫害に固有とは限らない。 |

標本の記録可能期間、測定できた年輪の範囲、個体が生存していた期間は、常に同じとは限らない。「何が観察できるか」と「何が実際に起きたか」を区別する。

# 研究例・参考リンク・レポート
## 虫害を、年輪の幅と組織から読む
Khasanov・Sandlersky（2018、R42）はオーク49個体と非寄主のトネリコ21個体を比較し、年輪内密度変動（IADF）と急な成長変化を検討した。問い：組織と比較樹種の情報で、狭い年輪だけでは言えない何を検討できるか。IADFは虫害に固有とは限らない。授業では調査設計の要約図を使い、組織写真は後日選定する。

## その他の研究例
コガネムシ類の周期的狭年輪（R41）は、年代照合にも影響し得る。周期だけでなく組織・被害記録・独立した年代根拠を確認する。スライドの指数グラフは合成例である。

Hirano・Morimoto（1999、R39）は汚染域と非汚染域のクロマツを比較した。気候モデルとSO₂濃度を組み合わせ、因果解釈をどう支えたかを読む。

# 発展事例：生存木・噴火・地震
## 一本のマツに重なる履歴
USGS（R43）はPinus albicaulisの標本で火傷、変色、枯死の履歴を紹介する。干ばつ・キクイムシ・菌など複数の要因を考え、枯死の単一原因を確定していない点に注目する。写真はリンクで参照し、後日教材図版としての利用を検討する。

## 虫害を生き残ったツガ
Walkerら（2014、R45）は6地点の生存木を比較し、3地点で成長低下、残りで不変または増加を報告した。Virginia Techの紹介記事（R44）から原論文に進む。生存者の偏りと、競争の変化などの代替説明を考える。

## セント・ヘレンズ山噴火
1980年5月18日の噴火の被害・生存分布を出発点とし、成長低下・傷・枯死・定着を読む。年輪火山学（dendrovolcanology）は、噴出物や地形と合わせて過去の噴火を検討する。噴火日が既知の1980年の事例と、年輪から過去の噴火を年代づける研究を区別する。

## サンアンドレアス断層の地震履歴
Wrightwoodでは1813年からの成長低下を、1812年末の地震と照合した（R47〜R49）。年輪地震学（dendroseismology）では、断層から離れた比較木や地層・歴史記録も使い、反応年と地震発生年を区別する。年輪地形学（dendrogeomorphology）への接続例である。
