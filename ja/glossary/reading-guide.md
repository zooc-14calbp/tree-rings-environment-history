# 年輪研究の難読用語集

入門講座「樹木年輪で読む環境と歴史」の日本語版です。専門用語の読みと、その場での意味を確認するときに使ってください。

ここに示す読みは、本講座で使う読みの目安です。用語の表記や意味の範囲には、分野・文献による違いがあります。説明はこの授業の文脈に合わせて短くまとめています。

## 樹木・木材の組織

| 用語 | 読み | この授業での意味・登場回 |
| --- | --- | --- |
| 木部 | もくぶ | 水や無機養分の通り道、体の支持などに関わる組織。木材は主に二次木部からなる。第1〜3回。 |
| 師部 | しぶ | 葉などで作られた同化産物の移動に関わる組織。木部との位置関係を観察する。第2回。 |
| 形成層 | けいせいそう | ここでは木部と師部の間にある維管束形成層を指す。内側に木部、外側に師部を作る。第2回。 |
| 仮道管 | かどうかん | 水の通導や支持に関わる細長い細胞。針葉樹材の構造を読む際の重要な手がかり。第2回。 |
| 道管 | どうかん | 広葉樹材などで水の通り道となる管状の構造。複数の道管要素が連なる。第2回。 |
| 木口面 | こぐちめん | 幹などの軸にほぼ直角な横断面。年輪の並びを観察する面。第2回。 |
| 辺材 | へんざい | 幹の外側にある木材の部分。水の通導や貯蔵に関わる。色だけでは心材と区別しにくい場合がある。第2回。 |
| 心材 | しんざい | 幹の内側の木材のうち、通常の通導機能と木材の生活細胞を失った部分。色の濃淡だけで判断しない。第2回。 |

# 年輪の構造と年代測定

## 年輪を観察するときの語

| 用語 | 読み | この授業での意味・登場回 |
| --- | --- | --- |
| 年輪 | ねんりん | 一年の生長に対応する層。輪のように見える境界がすべて一年を示すとは限らず、照合して確かめる。全体。 |
| 早材 | そうざい | 生長期の比較的早い時期に形成される木材の部分。細胞の特徴は樹種によって異なる。第2回。 |
| 晩材 | ばんざい | 生長期の比較的遅い時期に形成される部分。針葉樹では早材より細胞壁が厚い傾向がある。第2回。 |
| 偽年輪 | ぎねんりん | 同じ生長期の中の組織変化などによって現れる、年輪境界に似た構造。一年の境界と区別する。第2・3回。 |

## 年代測定の説明に出てくる語

| 用語 | 読み | この授業での意味・登場回 |
| --- | --- | --- |
| 壊変 | かいへん | 不安定な原子核が別の原子核などへ変わる過程。年代測定では、放射壊変の規則性を利用する。第1回。 |
| 較正 | こうせい | この項目では、放射性炭素年代と暦年代の対応を、較正曲線を用いて調べる手続きを指す。第1・5回。 |
