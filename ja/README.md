# 樹木年輪で読む環境と歴史

[English](../en/README.md) | [言語選択](../README.md)

年輪年代学を初めて学ぶ人のための入門講座です。各回90分、全8回。専門的な測定や統計の予備知識は必要ありません。

第1回は予習不要です。第1回の動画は授業後の復習・自主学習に使ってください。動画は旧スライドの読み上げ試作で、現在の教材と一致しない箇所があります。
