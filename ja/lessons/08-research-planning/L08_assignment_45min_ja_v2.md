# 最終レポートの課題と評価（2026年12月・当日45分版）

2日目の第8回、最後の45分に教室で作成・提出します。成績は最終レポートのみで評価し、授業中の発言・活動・学習状況は点数に含めません。

## 課題

年輪を用いて、過去の環境または歴史に関する問いを一つ考えてください。研究計画または文献・事例の検討の形で、次の4点を説明します。

1. 何を明らかにしたいか。対象となる地域・時代・資料は何か。
2. 年輪をどう観察・年代決定し、問いへの証拠にするか。
3. 別の解釈や比較すべき資料は何か。
4. 結論または見込みの限界と、次に確かめたいことは何か。

授業資料・手元のメモを参照できます。インターネット接続は必要ありません。用紙の枚数、文献数、図表の有無は採点条件にしません。引用した資料があれば、分かる範囲で出典を示してください。研究計画では、未実施の測定を結果として書かず、見込みとして区別してください。

## 評価の観点

5観点を各20点、合計100点で評価します。

| 観点 | 20点に相当する記述 |
|---|---|
| 問いと対象 | 問いが具体的で、地域・時代・対象が分かる。 |
| 資料・方法と問いとの対応 | 年輪資料や比較資料を選んだ理由、年代決定と解釈の手順が分かる。 |
| 比較と論理 | 別の解釈や比較対象を挙げ、根拠から主張までの道筋が分かる。 |
| 根拠・引用・図表の示し方 | 使った根拠を特定でき、図表がある場合は何を示すか説明する。 |
| 結論・限界・次の検討 | 言える範囲と不確実性を示し、次に確認すべきことを具体化する。 |

各観点で達成度に応じて20・15・10・5点を目安に採点し、記述がない場合は0点とします。文献の件数や用紙枚数そのものでは加減点しません。
