# 第1回日本語版：図・出典・参照資料

「樹木年輪で読む環境と歴史」入門講座。日本語版スライドv5の参照資料です。第1回の予習は求めず、授業後の復習にも使えます。図の近くに出典を示し、スライド内の出典名から原典や関連解説へ進めるようにしています。

## 6枚目：埋没木・出土木・古建築材

木曽埋没木、払田柵出土木、瑞巌寺の建築材。米延仁志（2021）「年輪と年縞からひもとく環境文明史」講演資料、30枚目の写真を再使用しました。元の講義資料から写真を取り出し、縦横比を保って配置しています。写真の撮影者を新たに推定してはいません。

- [年輪年代法を考古学に使う：米国国立公園局](https://www.nps.gov/articles/archeology-dendrochronology.htm)

## 11枚目：炭化トウモロコシ

セイバル遺跡の炭化トウモロコシ。米延仁志（2021）講演資料、92枚目の写真を再使用しました。架空の測定年代を写真の試料へ割り当てたものではありません。写真は実試料の例、演習のA〜Dは別の練習用設定です。

- [関連するセイバルの年代研究：Inomata et al.（2017）](https://doi.org/10.1073/pnas.1618022114)
- [放射性炭素法の試料と解釈：オックスフォード大学](https://c14.arch.ox.ac.uk/dating.html)
- [放射性炭素年代の較正](https://c14.arch.ox.ac.uk/calibration.html)

## 14枚目：魚梁瀬スギの実測曲線

米延仁志・星野安治・大山幹成（2021）「魚梁瀬スギ標準年輪曲線（1768〜2004）」『植生史研究』29（1）、15-19頁。既往講義「過去を探る科学・テキスト」34枚目に含まれる原図を再使用しました。説明の吹き出しを重ねた画像ではなく、元の図を使い、軸と目盛を保持しています。

灰色の線は試料ごとの年輪幅、太い黒線はまとめた系列です。下段は前年からの増減の一致を示します。年輪幅の縦軸は対数目盛です。実測値であり、現在の授業のために生成した模式データではありません。

- [原論文とPDF](https://doi.org/10.34596/hisbot.29.1_15)
- [照合の考え方：アリゾナ大学](https://www.ltrr.arizona.edu/eg/skelsurvey.html)

# 自然の記録の写真とウェブ資料

## 15枚目左：一ノ目潟の堆積物

米延仁志（2021）講演資料、69枚目の写真を再使用しました。堆積物の層が見える部分を表示しています。元の写真は保持し、写真部分の表示範囲を指定しました。写真だけで層の年数を確定する説明にはしていません。

## 15枚目右：GISP2の氷床コア

英語版Wikipediaの関連画像から参照できる、NOAA／USACEの写真です。深度1855 mのGISP2氷床コア、長さ19 cmの部分に年層が見えます。画像説明ページでは米国政府職員の職務上の作品としてpublic domainとされています。原画像の内容は変更せず、縦横比を保って配置しました。

- [画像の出典・説明・利用条件](https://commons.wikimedia.org/wiki/File:GISP2_1855m_ice_core_layers.png)
- [氷床コアの解説：英語版Wikipedia](https://en.wikipedia.org/wiki/Ice_core)
