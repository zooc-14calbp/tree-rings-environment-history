# 第2回 樹木の成長と木材・年輪の構造

90分。スライドL02_S01〜L02_S30に対応。確認問題は授業中の相談に使う。

## 学習の要点

一次成長（primary growth）は幹・枝・根の伸長。二次成長（secondary growth）は形成層などの活動による肥大。二つの活動時期は重なることがある。

形成層（vascular cambium）は内側に二次木部、外側に二次師部をつくる。樹皮全体がこの形成層からできるわけではない。

成熟した仮道管・道管要素は通常死細胞だが、辺材には生きた柔細胞もある。心材・辺材の色の違いは年輪界と同じ意味ではない。

年輪は一年分の木部であり、年輪界は隣り合う年輪の境目。輪の幅は暗い帯だけの幅ではない。

## 三方向と三断面

| 断面 | 含まれる方向・観察点 |
| --- | --- |
| 木口面（transverse） | R–T面。Lに直角。年輪幅はR方向に追う。 |
| 放射断面（radial） | L–R面。放射組織（ray）と軸方向細胞を比較。 |
| 接線断面（tangential） | L–T面。放射組織の高さ・幅などを比較。 |

L＝軸方向、R＝放射方向、T＝接線方向。放射組織は主にR方向に広がる。

# 用語と学習の手がかり

| 用語 | 簡単な解説 |
| --- | --- |
| 形成層（vascular cambium） | 木部と師部を生み出す分裂組織。 |
| 仮道管（tracheid） | 通水と支持に関わる細長い細胞。 |
| 道管（vessel） | 道管要素が連なった通水構造。 |
| 放射組織（ray） | 主に放射方向に広がる組織。 |
| 辺材／心材（sapwood / heartwood） | 外側の機能する木部と、内側で変化した木部。 |
| 早材／晩材（earlywood / latewood） | 成長輪の前半／後半にできる木部。 |
| 年輪界（tree-ring boundary） | 隣り合う年輪の境目。 |
| 偽年輪（false ring） | 年輪界に似た輪内の構造。 |
| 不連続年輪（discontinuous ring） | 幹の一部で形成されない年輪。 |

## 観察の整理

針葉樹では仮道管の内腔・壁厚、環孔材では大きな早材道管の集中が手がかりになる。散孔材でも境界付近の細胞や配列を調べる。不連続年輪は局所的に輪が途切れる現象であり、別方向・別試料を確認する。写真だけで失われた年数は確定できない。

写真の染色や照明による色は、木材本来の色とは限らない。偽年輪は輪内の変化であり、途切れる不連続年輪と区別する。マカンバの標本へのリンクは第2回の参考資料に残してある。
