# A3透明フィルムで年輪曲線を重ねる

[受講者用PDF：参照曲線と試料A（2ページ）](crossdating_films_A3_ja_v1.pdf) · [教員用解答PDF](crossdating_films_answer_A3_ja_v1.pdf)

## 準備

受講者用PDFの1ページ目（参照曲線）はA3横向きの普通紙に、2ページ目（試料A）はA3横向きの透明フィルムに印刷します。両方とも100%（実際のサイズ）で出力し、拡大・縮小を無効にします。印刷後、各ページの100 mm確認線を定規で測り、100 mmであることを確かめます。試料Aの透明フィルムを参照曲線の普通紙に重ねて横へ動かします。白い紙を下敷きにすると曲線を見やすくできます。横軸は1年＝3 mmです。

## 実習

1. 実線の参照曲線に、破線の試料Aを重ねます。縦軸の同じ値の目盛りをそろえます。
2. 試料Aを横に動かし、狭い輪・広い輪の並びがまとまって重なる位置を探します。
3. 谷や山を少なくとも3か所選び、その間隔や周囲の変動を比較します。1か所だけで決めないでください。
4. 最初の輪の候補年を読み、60輪すべての範囲で一致と不一致を確認します。形が完全に重なる必要はありません。
5. 別の位置を一つ試し、なぜ最初の候補のほうがよいかを言葉で説明します。

授業内の練習であり、採点対象ではありません。従来の照合演習枠で実施し、スケルトンプロットは方法の紹介にとどめます。旧合成演習は任意の復習に使えます。

## 曲線の由来と限界

試料Aはコウヤマキの実測系列の一部です。参照曲線は対象個体を除く26個体から教材用に再計算しました。各個体の1800〜1899年の平均幅を1とし、相対幅を年ごとに平均しています。原著論文の標準年輪曲線をそのまま転載したものではありません。年齢に伴う傾向を除く処理はしていません。

これは既知年代を伏せた60輪の練習です。分かりやすい一致を含む区間を選んでいます。重ね合わせだけで未知試料の年代を確定できることや、特定の相関値を年代確定基準にすることは示しません。実研究では全系列、別の測線や個体、組織の観察、統計的な照合を組み合わせます。

スケルトンプロットの適否は、樹種名だけで一律には決まりません。今回の資料と受講者には、曲線全体の直接比較を主実習とします。

出典：[米延ほか（2026）コウヤマキ研究](https://doi.org/10.1016/j.dendro.2026.126565)、[研究データ](https://doi.org/10.50974/0002007852)。実物フィルムでの印刷・操作確認は未実施です。
