# 樹木年輪で読む環境と歴史

Reading Environment and History through Tree Rings

米延仁志 / Hitoshi Yonenobu · 更新 / Updated 2026-10-30 · v2026.10.30

年輪年代学の入門から、年輪考古学・年輪生態学・年輪気候学まで学ぶ全8回の教材です。日本語・英語のスライドPDF、配布資料、章別解説動画、補助教材、日英用語集を収録しています。

Eight lessons introduce dendrochronology and its archaeological, ecological and climatic applications. Materials are available in Japanese and English.

## 教材について / About these materials

対面授業は各回90分です。動画は解説部分を4章に分けたもので、演習・対話の時間を含む90分とは区別します。英語音声はAria、日本語音声はNanamiの合成音声です。字幕（SRT・VTT）と台本も各回にあります。

初稿として公開しています。合成データ・理想モデル・模式図はその旨を明記しています。実測データ・現物写真への更新を予定しています。論文から紹介する報告値は説明用の合成例と区別しています。

These are draft teaching materials. Synthetic data and schematics are labelled; empirical and specimen-based updates are planned. Reported research statistics remain distinct from synthetic examples.
